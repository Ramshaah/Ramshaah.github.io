Machine Learning · Healthcare Analytics

Understanding Health Risk & Healthcare Costs

Developed predictive models across four healthcare datasets to identify the strongest drivers of health risk, utilization, and cost. The work combined model development with a practical interpretation of how insurance, chronic conditions, emergency-room use, prescriptions, and age influence outcomes.

0.97MEPS XGBoost AUC
0.91Framingham logistic AUC
4Healthcare datasets
PythonXGBoostLogistic RegressionFeature AnalysisModel Evaluation

Research questions

Which demographic, behavioral, and clinical features predict cardiovascular disease? Which patients are likely to enter the highest healthcare-spending quartile?

Analytical pipeline

Data cleaning, exploratory analysis, feature engineering, dimensionality reduction, cross-validation, hyperparameter tuning, classification, clustering, and model interpretation.

MEPS HC-244XGBoost · AUC 0.97High-cost patient prediction · 94% accuracy
Statlog HeartRandom Forest · AUC 0.92Clinical heart-disease classification · 87% accuracy
CardioElastic Net · AUC 0.78–0.79Population screening across 55,699 cleaned records
FraminghamRegularized Logistic · AUC >0.90Long-term hypertension risk prediction

What the analysis revealed

  • Age, blood pressure, and cholesterol consistently predicted cardiovascular risk.
  • Prescription spending, chronic conditions, emergency-room use, and insurance coverage drove high-cost status in MEPS.
  • Smoking, diabetes, BMI, and physical activity created actionable prevention signals.
  • The models support earlier intervention, targeted case management, and more efficient resource allocation.

CDS DX 604: Data Management at Scale

Learned to design cloud data systems in Microsoft Azure, moving from raw public data to governed storage, relational and NoSQL databases, distributed processing, serverless analytics, and decision-ready dashboards.

Project story, not submission files: this section summarizes the architecture, tools, and skills demonstrated in the coursework. Original screenshots, grades, account identifiers, and submission records are not published.

The learning journey

From a raw file to a scalable analytics system

I learned data management by building each layer of a modern cloud pipeline. The work began with acquiring imperfect public data, progressed through structured and semi-structured storage, and ended with serverless querying and an interactive business intelligence layer.

End to endIngest · Store · Transform · Query · Present
01Acquire

Connected Azure Data Factory to public web sources and automated file retrieval instead of relying on manual uploads.

02Store

Organized cloud resources, Blob Storage, SQL databases, Cosmos DB containers, and an ADLS Gen2 data lake.

03Transform

Decompressed source files, enforced schemas, mapped fields and types, cleaned edge cases, and converted text into partitioned Parquet.

04Query

Used relational SQL, the Cosmos DB Core SQL API, and Synapse serverless SQL to work across tables, documents, nested arrays, and files.

05Present

Connected the analytical layer to Power BI and created calculated fields, charts, tables, and interactive filters.

Structured pipeline

Public safety data into Azure SQL

Built a repeatable ingestion process for compressed NHTSA vehicle-safety data. The pipeline extracted files from the web, loaded and decompressed them in Azure Storage, applied an explicit schema, and staged clean records in a typed Azure SQL table.

  • Designed linked services, datasets, copy activities, and schema mappings in Azure Data Factory.
  • Translated reference documentation into appropriate SQL column order, data types, and text lengths.
  • Validated the load with SQL queries and learned to troubleshoot delimiters, firewall access, and pipeline failures.

Semi-structured data

NoSQL with Azure Cosmos DB

Extended the same cloud environment to JSON movie data, learning how document databases handle nested structures differently from relational tables.

  • Created and configured a Cosmos DB database and container with a purposeful partition key.
  • Used Data Factory to load JSON directly into the document store.
  • Queried nested arrays and attributes with the Core SQL API while considering request-unit cost and global distribution.

Lakehouse-style analytics

Data Lake, Synapse & Power BI

Connected storage, distributed transformation, serverless analytics, and visualization into one cloud analytics stack.

  • Used ADLS Gen2 hierarchical storage and a Mapping Data Flow to convert text into partitioned Parquet files.
  • Configured access controls and queried an external table in place through a Synapse serverless SQL pool.
  • Connected Power BI to the serverless endpoint and built an interactive report with calculated fields and filters.

Business Analytics · Food Security

Food Safety in Sub-Saharan Africa

For my Business Analytics capstone, my team examined food insecurity across Sub-Saharan Africa and explored which structural factors could help explain differences between countries and over time. The project moved from public-data discovery and cleaning to statistical modeling, machine-learning comparison, and policy-focused interpretation.

Core questionHow are irrigation infrastructure and reliance on food imports associated with the prevalence of severe food insecurity?
01 · Prepare

Build an analysis-ready dataset

Sourced regional indicators, handled missing observations, aligned variables, and integrated country-year records using Excel and R.

02 · Explore

Make relationships visible

Created scatterplots and fitted trend lines to examine severe food insecurity against irrigated arable land and food-import dependence.

03 · Model

Control for place and time

Used multiple linear regression with country and year treated as factors, helping separate the predictor relationships from persistent geographic and temporal differences.

04 · Compare

Test alternative approaches

Extended the analysis in RapidMiner by comparing linear regression with decision-tree and neural-network methods.

Outcome studiedPrevalence of severe food insecurity
Key predictorsIrrigated arable land and food imports
Analytical lensCountry and year effects

What I learned

The project strengthened my ability to turn an open-ended social problem into a structured analytical workflow: define measurable variables, verify and clean public data, select appropriate models, communicate limitations, and translate technical results into evidence that policymakers can use to prioritize food-system investment.
